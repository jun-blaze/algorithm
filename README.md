# Algorithm Practice

프로그래머스 문제 풀이와 코딩 테스트 학습 기록을 모아 둔 저장소다. Java 풀이를 중심으로 문제 유형별 구현과 풀이 과정을 정리한다.

## 구성

| 경로 | 내용 |
|---|---|
| `src/programmers/lessons/` | 기초 문제 풀이 |
| `src/programmers/lessons2/` | 추가 문제 풀이 |
| `src/programmers/pcce1/` | PCCE 기출 문제 |
| `src/programmers/pcce_mock3/` | PCCE 모의고사 |
| `src/programmers/pccp1/` | PCCP 기출 문제 |
| `src/doit/` | 알고리즘 교재 실습 |

## 풀이 규칙

- 파일명에 플랫폼 문제 번호와 짧은 영문 이름을 함께 기록한다.
- 제출 코드와 학습용 구현을 구분하고, 다시 볼 내용은 코드 주석으로 남긴다.
- 생성된 클래스 파일보다 `src/`의 원본 코드를 기준으로 본다.

## 실행

별도 빌드 도구 없이 JDK가 설치된 IDE에서 원하는 클래스를 실행한다. 명령줄에서는 저장소 루트 기준으로 다음과 같이 컴파일할 수 있다.

```bash
javac -d out src/programmers/pccp1/P01_242258_BandageWrapping.java
```

개인 학습용 저장소이며 문제의 저작권과 이용 조건은 각 플랫폼 정책을 따른다.

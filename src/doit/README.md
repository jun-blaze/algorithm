## 파일 규칙

```
D<책강의번호 3자리>_<백준문제번호>_<문제이름>.java
예) D027_9663_NQueen.java  →  강의 27번, 백준 9663, N-Queen
```

- `D` = Do it!, 뒤의 3자리 번호로 파일이 강의 순서대로 정렬됨.
- 클래스 구조는 `programmers.pcce1` 패키지와 동일한 양식:
  - 상단 블록 주석: 문제 설명 / 핵심 아이디어 / 제한사항 / 입출력 예
  - `main` : 입출력 예로 테스트
  - `solution(...)` : 직접 풀어보는 자리 (pesudo 주석 + TODO)
  - `answer(...)` : 스스로 풀어본 뒤 확인하는 정답 코드

## 27. N-Queen (백준 9663) 요약

N × N 체스판에 퀸 N개를 서로 공격 불가능하게 놓는 경우의 수.

- 퀸은 한 행에 하나 → `A[row] = col` 1차원 배열로 배치 저장.
- `row` 를 0 → N-1 로 늘리며 각 행의 열을 완전 탐색하되,
  이전 퀸과 충돌하면 재귀를 멈추고 되돌아감(백트래킹 = 가지치기).
- `row == N` 도달 시 경우의 수 +1.
- 충돌: 같은 열 `A[i] == A[row]`, 같은 대각선 `|row-i| == |A[i]-A[row]|`.
- 시간복잡도는 대략 O(N!) 수준이지만 가지치기로 실제 탐색량이 크게 줄어듦. (N < 15)
